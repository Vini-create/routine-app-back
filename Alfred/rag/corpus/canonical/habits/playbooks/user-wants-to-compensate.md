# User Wants to Compensate for Missed Work

## Activation criteria

After one or more missed nonclinical activities, the user proposes adding the missed volume to a later session or sharply increasing workload to restore a plan or streak.

## Similar situations that should not activate this playbook

Do not apply to medication, exercise rehabilitation, eating, substance use, debt repayment or any domain where compensation has medical, legal or financial implications. Use simple lapse recovery when the user only wants to resume.

## Possible explanations

The user may treat scheduled volume as debt, fear that prior progress disappeared, face a real fixed deadline, use a consecutive record as the target, or underestimate the cost of combining sessions.

## Missing information

What was missed, whether the missed output remains necessary, current capacity, deadline and consequences, safety constraints, dependencies, ordinary session load and whether redistribution is permitted.

## Response objective

Choose explicitly among resume, redistribute or drop. Prevent an untested load spike while acknowledging genuine deadlines and obligations.

## Decision path

- If missed work no longer has value or requirement, drop it explicitly and resume the current plan.
- If the behavior is cumulative and a deadline is flexible, redistribute across several feasible opportunities.
- If a fixed deadline requires the output, revise scope, obtain support or renegotiate before increasing load.
- If the proposal exceeds recent demonstrated capacity, retain the ordinary or graded version.
- If health or safety could be affected, stop routine coaching and use the appropriate boundary.

## Candidate strategies

Ordinary resumption, bounded redistribution, scope change, deadline negotiation, additional support or deliberate omission.

## Conditions for selecting each strategy

Redistribution requires genuine spare capacity and a defined end. A larger session needs domain-appropriate safety and prior evidence of tolerability; emotional urgency is not sufficient evidence.

## When to ask a question

Ask whether the missed work is still required for a real outcome or only for restoring the original schedule.

## When to respond directly

Respond directly when the work is optional, the next ordinary opportunity is available and no safety-sensitive domain is involved.

## What to avoid

Do not describe missed work as debt, endorse punishment, infer that doubling is harmless, or optimize around a streak counter.

## Suggested next step

State which of resume, redistribute or drop applies, then schedule only the load supported by current conditions.
