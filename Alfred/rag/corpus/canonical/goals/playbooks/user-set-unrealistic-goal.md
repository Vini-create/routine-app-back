# User Set an Unrealistic Goal

## Activation criteria

A specific target, pace or deadline appears incompatible with demonstrated capacity, available time, prerequisite skill, resources or dependencies, and the user wants to revise it.

## Similar situations that should not activate this playbook

Use vague-goal routing when no target exists, insufficient-capacity routing when a temporary condition affects an otherwise feasible plan, and conflicting-goals routing when the main problem is competition between valued targets.

## Possible explanations

The baseline may have been assumed rather than observed, duration underestimated, several load dimensions increased together, an external dependency ignored, uncertainty hidden by a point estimate, or the target inherited from someone else.

## Missing information

Current performance, exact target and deadline, recent actual durations, fixed constraints, missing skills or resources, dependent people or events, acceptable minimum and consequences of changing the target.

## Response objective

Identify the limiting variable and preserve the goal's value while changing the smallest element needed for a credible test. Avoid declaring the person incapable or promising that ambition alone closes the gap.

## Decision path

- If the deadline is externally fixed, adjust scope, support or sequence rather than pretending time can expand.
- If skill is missing, insert learning or assistance before performance escalation.
- If recent cost or failure clusters at a high dose, select a feasible grade with a progression condition.
- If duration estimates are unsupported, use comparable actuals and a range.
- If the goal is imposed or no longer worth its cost, review endorsement before recalibration.

## Candidate strategies

Scope reduction, deadline revision, resource or skill acquisition, graded progression, time-estimate correction and deliberate goal review.

## Conditions for selecting each strategy

Change only the variable supported by evidence. Preserve safety margins and do not alter medical, legal, academic or professional obligations without appropriate authority.

## When to ask a question

Ask which constraint makes the current target least plausible when several explanations remain possible.

## When to respond directly

Respond directly when baseline, target and limiting constraint are explicit and the user controls the relevant adjustment.

## What to avoid

Do not label every ambitious goal unrealistic, replace evidence with a generic percentage reduction, or shrink the goal until it no longer represents the desired behavior.

## Suggested next step

Revise one of scope, pace, deadline or support, record the reason, and define the observation that will trigger the next review.
