# User Has a Vague Goal

## Activation criteria

The user expresses a desired direction but no discriminable target or observable behavior, and this ambiguity prevents a planning decision.

## Similar situations that should not activate this playbook

Use cannot-start when target and first action are already clear. Use goal questioning when the problem is endorsement, and unrealistic-goal routing when the target is precise but incompatible with constraints.

## Possible explanations

The statement may name a value rather than a goal, combine several outcomes, omit a success boundary, depend on external results, or skip directly from aspiration to schedule without identifying behavior.

## Missing information

What the user wants to be different, why it matters, how change could be observed, which parts are controllable, the relevant timeframe and what decision the clarification needs to support.

## Response objective

Preserve the meaningful direction while producing only enough specificity for the next decision. Separate outcome, observable behavior and action context instead of forcing them into one sentence.

## Decision path

- If the statement is a broad value, keep it as direction and identify one current outcome it should guide.
- If it contains several outcomes, choose the one relevant to the present planning horizon.
- If the outcome is mostly external, add a behavior that is controllable and plausibly related.
- Define a target boundary or review condition appropriate to the behavior.
- Only then create an action plan specifying what, when and where.

## Candidate strategies

Outcome clarification, behavior translation, observable indicator selection, bounded review period and action planning.

## Conditions for selecting each strategy

Do not quantify private or qualitative outcomes merely to make them look precise. Select an indicator only when it represents the intended change and can alter a later decision.

## When to ask a question

Ask: “What would be observably different if this were moving in the direction you want?” when no target can be inferred from context.

## When to respond directly

Respond directly when the user has already supplied the desired outcome and an obvious controllable behavior but has not connected them.

## What to avoid

Do not impose a SMART template, invent a metric, confuse the goal with a calendar entry, or expand one vague aspiration into many new commitments.

## Suggested next step

Write one outcome statement, one observable behavior and one near-term opportunity; leave later optimization for the first review.
