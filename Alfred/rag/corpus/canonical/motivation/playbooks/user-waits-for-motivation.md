# User Is Waiting to Feel Motivated

## Activation criteria

The user explicitly treats a preferred motivational state as a prerequisite for a chosen, noncritical action, or reports repeated opportunities where action depends on day-to-day willingness.

## Similar situations that should not activate this playbook

Do not use when the user rejects the goal, reports exhaustion or acute symptoms, lacks a prerequisite, or is asking for emotional support without requesting action. Those situations require autonomy, capacity, security or conversational routing first.

## Possible explanations

Motivation may fluctuate naturally, the goal may be only partly endorsed, the action may be too costly, the opportunity may be vague, or waiting may provide immediate relief from an aversive task.

## Missing information

Whether the goal is still chosen, the latest real opportunity, current energy and health constraints, the smallest useful action, what happens on higher-motivation days and whether low motivation is persistent across life domains.

## Response objective

Validate the current state without making it a character judgment or a permanent gate. Then determine whether to review the goal, adjust capacity or create an action less dependent on a momentary decision.

## Decision path

- If the goal is not endorsed, review or release it instead of optimizing execution.
- If low energy or concerning symptoms are present, leave this playbook for the appropriate gate.
- If the action exceeds current capacity, choose a feasible grade before scheduling it.
- If the goal and capacity remain adequate, anchor one useful action to a recurring opportunity or use a specific if-then plan.
- If the pattern is unclear, compare motivation and behavior across a few real opportunities.

## Candidate strategies

Goal-autonomy review, capacity adjustment, opportunity-based action planning, implementation intention, or minimal paired monitoring of state and action.

## Conditions for selecting each strategy

Planning is appropriate only after endorsement and feasibility checks. Monitoring should be brief and should answer whether action truly covaries with motivation.

## When to ask a question

Ask whether the user would still choose the goal if nobody expected it when endorsement is uncertain. Otherwise ask about the latest opportunity.

## When to respond directly

Respond directly when the user clearly values the goal, has adequate capacity and already names a recurring opportunity.

## What to avoid

Do not say motivation never matters, prescribe discipline, use shame, or create an oversized commitment during a temporary motivational surge.

## Suggested next step

Choose one next opportunity and one feasible action that can occur even if willingness is ordinary, then review the result rather than the mood alone.
