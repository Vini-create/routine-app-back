# User Cannot Start a Chosen Task

## Activation criteria

The user has chosen a task and describes a recent opportunity in which the
first task-producing action did not occur.

## Similar situations that should not activate this playbook

Do not activate when there was no real opportunity, the task lacks basic
instructions, the user rejects the goal, or tiredness is the stated barrier.

## Possible explanations

The first action may be ambiguous; a prerequisite skill or resource may be
missing; preparation may provide an easier immediate reward; the task may feel
aversive; or anticipated evaluation may block exposure.

## Missing information

The most recent start opportunity, what the user did instead, whether the first
action was known, and whether time, materials and prerequisite skill were
available.

## Response objective

Identify the most plausible start barrier and select one matching intervention,
without treating non-initiation as a character defect.

## Decision path

- If the first action is unknown, define one observable task-producing action.
- If a prerequisite is missing, resolve instruction, example, access or help before planning execution.
- If preparation repeatedly replaces production, place a boundary around preparation and begin with an output.
- If the action is beyond demonstrated capacity, select a smaller graded component with an explicit progression condition.
- If immediate relief or a nearer reward repeatedly wins, bring a task consequence or feedback point closer rather than adding task detail.
- If anticipated evaluation is the barrier, define the required standard and a proportionate exposure to real feedback.
- If the same environmental obstacle recurs, change that observed cue or access step rather than redesigning the whole task.
- If the goal is not endorsed, leave this playbook and evaluate goal autonomy.

## Candidate strategies

Action planning, prerequisite resolution, graded task structure, consequence or
feedback proximity, fit-for-purpose exposure and environmental-friction change.

## Conditions for selecting each strategy

Use action planning for ambiguity, graded structure for a capacity gap, resource
preparation for a concrete missing dependency, reward-timing change for a
repeated immediate-payoff pattern, exposure for evaluative avoidance and an
environmental change only when the same barrier is observed across episodes.

## When to ask a question

Ask one question when the answer distinguishes two different branches, usually
about the latest start opportunity or the first known action.

## When to respond directly

Respond directly when task, antecedent, substitute action and missing condition
are already explicit.

## What to avoid

Do not provide a generic productivity list, assume low motivation, or reduce a
task whose missing prerequisite has not been addressed.

## Suggested next step

Define or prepare the single first task-producing action that corresponds to
the supported branch.
