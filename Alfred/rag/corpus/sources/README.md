# Source storage boundary

This tree is never embedded or returned as Alfred context.

- `original/`: original material only when storage and commercial use are authorized.
- `open_access/`: authorized open-access copies.
- `external_references/`: pointers and metadata, never unlicensed copies.
- `derived_notes/`: original editorial notes linked to a `source_id`.

The current repository stores no source PDF. Scientific retrieval content lives
under `canonical/*/knowledge/` and cites records from `source_registry.jsonl`.
