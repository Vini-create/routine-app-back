11. Implementar logs de eventos
Habit = definição do hábito.
HabitLog = evento de execução.

RoutineItem = item da rotina.
RoutineItemLog = evento de execução.

Exemplo:
Usuário marcou hábito como feito
→ POST /habits/{habit_id}/logs
→ salva no Postgres
→ recalcula consistência/streak

12. Criar métricas básicas
Antes da IA:
- consistency_score
- current_streak
- best_streak
- taxa de conclusão da rotina
- quantidade de falhas
- hábitos mais consistentes

13. Criar CoachBot simples
Fluxo:
- recebe mensagem
- busca últimas 10 mensagens
- busca últimos 2 feedbacks
- busca perfil do coach
- monta prompt
- chama LLM
- salva mensagem do usuário
- salva resposta do assistente
- retorna ao front

14. Criar Feedbacker
Fluxo:
- recebe pedido de feedback
- busca metas
- busca hábitos
- busca logs de hábitos
- busca rotina
- busca logs da rotina
- calcula métricas
- monta prompt analítico
- LLM gera JSON
- salva em feedbacks.content
- retorna ao front

15. Criar Orchestrator/LangGraph
Fluxo:
Frontend
→ Backend
→ Router Node
→ Conditional Edge
→ CoachBot ou Feedbacker

Preferência:
o front já manda request_type:
- coach_chat
- feedback_analysis

16. Criar logs técnicos de IA
Tabela:
ai_usage_logs

Guardar:
- user_id
- feature_name
- provider

- output_tokens
- total_tokens
- latency_ms
- status
- created_at

17. Revisar segurança
- usuário só acessa dados próprios
- toda query filtra por user_id
- CORS configurado
- rate limit em auth e IA
- validação com Pydantic
- secrets no .env
- nunca logar senha/token/conteúdo sensível

18. Revisar LGPD
- não coletar CPF, RG, endereço, saúde, política, religião etc.
- guardar só dados necessários
- permitir exclusão/anomização
- user_consents para termos, privacidade e uso de IA
- não mandar dados desnecessários para o LLM
